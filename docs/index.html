Privacy

There is no server to breach

Not a promise in a policy — the app simply has nowhere to send your data.

  • No sign-up. It works the moment it installs.
  • No analytics, no ad or crash SDKs — the build carries none.
  • No sync. Rows live in a Room (SQLite) database on the phone.
  • No connection needed for OCR, parsing, charts or backups.

One optional call: with store lookup on, a receipt’s NIP goes to Poland’s public VAT registry for the company’s legal name. Off by default. Full policy.

Questions people actually ask

Is this open source?

The source is public and readable, but no licence file has been published yet, so all rights are reserved for now. If you want to reuse code, open an issue and ask.

Does it need the internet?

No. OCR, invoice parsing, charts, backups and reminders all run offline. The only network feature is an optional VAT-registry lookup that is switched off by default.

Which phones?

Android 7.0 (API 24) and newer, portrait phones first. A camera helps; you can also import pictures or PDFs from the gallery and other apps.

How do I get my data out?

CSV export for spreadsheets, CSV import to move in, plus a full .skb backup you can encrypt with AES-256-GCM and a password.

Is there a Play Store build?

Not published today. This repository is the only release channel, and release signing config stays private.
